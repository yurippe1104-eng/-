# 表紙（サムネイル）づくりの道具（発信部）
シリーズ「〇〇円仕入れ」の表紙を、型を固定したまま作る。
- お店のロゴは使わず、文字だけ（「ハードオフで」など）
- お札には必ず「見本」を入れる
- 金額と商品写真は画面の真ん中寄り（プロフィール一覧で切れないように）

使い方：`node make.js <お店> <仕入れ値> [相場 or -] [商品写真 or -] [出力先]`
例：`node make.js ハードオフ 880 4800 photo.jpg ../../thumbnails/out.png`
