# ネタ帳（発信部）— 社長が売ってきたもの × 見せ方
「みんな知ってる系」でなくても、見せ方（型）を変えればネタになる。

| 商品 | 見せ方の型 | 最初の1.5秒の例 |
|---|---|---|
| デジカメ（平成のコンデジ） | 流行り型：今、若い子に人気 | 「〇〇円のデジカメ、〇〇円で売れた！」 |
| ビデオカメラ | 謎・理由型：なぜ今これが売れる？ | 「今どきビデオカメラ、誰が買う？」 |
| ワープロ | クイズ型：誰が買ったと思う？ | 「ワープロ、まさかの〇〇円」 |
| イヤホン | 意外型：片方だけ／ジャンクでも売れる | 「片耳だけのイヤホンが売れた」 |
| ゴルフバッグ | 大物型：リサイクルショップの大物 | 「〇〇円のゴルフバッグが〇〇円に」 |
| ラタン家具 | 流行り型：インテリアで人気 | 「〇〇円のラタン家具が〇〇円で旅立ち」 |
| 変な色の家具 | クイズ型：これ売れると思う？ | 「この色の家具、売れると思う？」 |
| たまごっち（12,420円） | みんな知ってる型 | 「〇〇円のたまごっちが12,420円に」 |

## ネタ切れしないための型
1. みんな知ってる型（キティ、ピカチュウ、たまごっち）
2. クイズ型（これ何？／誰が買う？／いくらで売れたと思う？）
3. 意外型（動かないのに売れた／片方だけ売れた）
4. 流行り型（今、若い人に人気）
5. 大物型（家具・ゴルフバッグなど大きいもの）
6. 見分け方型（赤タグ、初期など）
7. 失敗談型（売れなかった・失敗した仕入れ）

## 商品の利益を出さないリール（2026-11-28）
| 型 | 最初の1.5秒の例 |
|---|---|
| やってはいけない型 | 「ジャンク仕入れで やっちゃダメなこと3つ」 |
| 失敗談型 | 「1,000円で買って 1円も売れなかったもの」 |
| 見分け方・チェック型 | 「ジャンク棚で 最初に見る場所はここ」 |
| 3児ママの1日型 | 「3児ママが 仕入れに使える時間は1日30分」 |
| あるある型 | 「リサイクルショップ仕入れ あるある」 |
| 質問に答える型 | 「Q. 資金いくらから始められる？」 |
| 思い込みをくずす型 | 「ジャンク品＝売れない、は間違いです」 |
| ビフォーアフター型 | 「汚れたジャンク品 → 出品写真」 |
| 数字の報告型 | 「今月の仕入れ 合計〇円」 |
| POV（その場目線）型 | 「POV：子どもを送ったあとの30分で仕入れ」 |

## 「ちょっと待って！」型（3回に1回くらい）
- 金額の驚き：ちょっと待って！ 330円のキティが5,980円
- 捨てないで型：ちょっと待って！ その古いぬいぐるみ、捨てないで
- 見逃し型：ちょっと待って！ これ、ブックオフで見つけたら買って
- 正体クイズ型：ちょっと待って！ これ、何かわかる？
- 家にあるかも型：ちょっと待って！ おうちに昔のピカチュウない？
- 見分け方型：ちょっと待って！ このタグ、見たことある？
