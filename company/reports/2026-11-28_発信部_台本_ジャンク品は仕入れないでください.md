# 台本：「ジャンク品は仕入れないでください」（否定型・姉さんがしゃべる形）
約20秒。最初の1.5秒は否定の一言で止める。

| 秒 | 画面 | テロップ |
|---|---|---|
| 0〜1.5 | ジャンク棚の写真＋大きな文字 | 「ジャンク品は 仕入れないでください」 |
| 1.5〜4 | 社長の手元・棚 | 「…ただし“見るポイント”を知らないうちは」 |
| 4〜7 | 失敗した商品の写真 | 「わたしも最初は 1,000円で買って 売れなかった物がありました」 |
| 7〜10 | チェックの写真① | 「見るポイント① 〇〇」 |
| 10〜13 | チェックの写真② | 「見るポイント② 〇〇」 |
| 13〜16 | チェックの写真③ | 「見るポイント③ 〇〇」 |
| 16〜18 | 売れた商品の写真（キティ・ピカチュウなど） | 「知っていれば ジャンク棚は宝の山」 |
| 18〜21 | 文字だけ | 「あなたは ジャンク品 買ったことある？ コメントで教えてね／保存して仕入れのときに見返してね」 |

## 社長に確認すること
- 見るポイント3つ（例：型番・付属品・ブランドやタグ・動かない理由・相場の確認 など）
- 失敗した商品（あれば）
- 使える写真（ジャンク棚、手元、失敗した物、チェックしているところ）
