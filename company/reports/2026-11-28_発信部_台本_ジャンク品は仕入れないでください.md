# 台本：「ジャンク品は仕入れないでください」（否定型・姉さんがしゃべる形）
約20秒。商品は見せない（出品中の物がバレないように）。

| 秒 | 画面 | テロップ |
|---|---|---|
| 0〜1.5 | ジャンクのカゴ・袋の写真 | 「ちょっと待って！」（小）／「ジャンク品は 仕入れないでください」 |
| 1.5〜4 | 同じ写真 | 「…この3つを知らないうちは」 |
| 4〜8 | くしゃくしゃの袋 | 「① くしゃくしゃの袋は 見ない」「長く残っている＝みんなが見たあと」 |
| 8〜12 | パリッとした新しい袋 | 「② パリッとした 新しい袋を見る」「入ったばかりの お宝候補」 |
| 12〜16 | スマホで売り切れ（SOLD）を調べる手元 | 「③『売れそう』だけで 買わない」「売れた実績を 調べてから」 |
| 16〜18 | 文字だけ | 「ここを知れば ジャンクのカゴは 宝の山」 |
| 18〜21 | 文字だけ | 「ジャンク品、買ったことある？ コメントで教えてね／保存して 仕入れのときに 見返してね」 |

## 必要な写真（なければ文字だけで作れる）
1. ジャンクのカゴ・袋がたくさん並んでいる写真
2. くしゃくしゃ・色あせた袋のアップ
3. パリッとした新しい袋のアップ
4. スマホでメルカリの「売り切れ」を調べている手元（画面はぼかす）
※値札の店番号・バーコード、出品中の自分の商品は写さない
