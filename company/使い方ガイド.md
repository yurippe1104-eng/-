# 使い方ガイド（社長用）

## 1. Claude と Claude Code の使い分け
| こんなとき | 使うもの |
|---|---|
| ちょっとした相談、アイデアの壁打ち、雑談 | **Claude**（ふつうのチャット） |
| 会社の仕事（分析、出品、経理、リマインド、部署への指示） | **Claude Code**（この会社） |

## 2. Claude Code で会社を開く方法
1. Claude アプリの **Code** を開く
2. 新しいセッションを始めるとき、リポジトリに **このリポジトリ** を選ぶ
3. あとは話しかけるだけで、会社のルールと部署が自動で読み込まれます

## 3. 頼み方の基本（これだけ覚えればOK）
**「〇〇部に、△△をお願い。□□があればそれも見て」**

- 部署名は言わなくても大丈夫です。内容から自動で振り分けます。
- 「急ぎ」「ざっくりでいい」「じっくり考えて」も一言そえると精度が上がります。
- データ（CSV・Excel・スクリーンショット）は、そのまま貼り付けて送ってOKです。

## 4. 部署ごとの頼み方の例（コピペして使えます）

### 秘書室
- 「今日やることを整理して、優先順位をつけて」
- 「毎週月曜の朝9時に、今週の仕入れ予定を知らせて」
- 「明日の15時に、発送するようにリマインドして」
- 「今日の予定と、返事が必要なメールをまとめて」（カレンダー・Gmail連携が必要）

### 仕入れ部
- 「この商品、仕入れ値〇円でメルカリで〇円で売れそう。利益出る？」
- 「今の季節に仕入れたほうがいいジャンルを考えて」

### 出品部
- 「この商品の出品タイトルと説明文を作って。商品：〇〇、状態：〇〇、サイズ：〇〇」
- 「この出品が売れない理由と、直し方を教えて」（出品画面のスクショを貼る）

### 営業・販売部
- 「1か月売れてない在庫、値下げする？どれくらい？」
- 「来月のセール企画を3つ考えて」

### 分析部
- 「先月の売上データを分析して、売れ筋と死に筋を教えて」（CSVを送る）
- 「月ごとの利益の推移をグラフにして」

### 広報・SNS部
- 「このリールがバズった理由を分析して」（インサイトのスクショを送る）
- 「伸びた動画と伸びなかった動画を比べて、次に何を変えればいいか教えて」
- 「来週投稿するリールの企画と台本を3本作って」

### 顧客対応部
- 「このお客さんへの返信文を作って」（メッセージを貼る）
- 「値下げ交渉が来た。〇円までならOK。上手な断り方/返し方を作って」

### 経理部
- 「今月の売上と経費をまとめて、利益を出して」
- 「確定申告のために、今から何を準備しておけばいい？」

### 複数の部署にまとめて頼む
- 「会議を開いて。テーマは『来月の売上を20%上げるには』。仕入れ部・営業部・SNS部の意見を出して、最後にまとめて」
- 「月末報告をして。分析部と経理部で今月の数字をまとめて、次の月にやることを決めて」

## 5. 最初にやること（おすすめ順）
1. `会社情報.md` を埋める（「会社情報を埋めたいから質問して」と言えば、Claude が1つずつ聞きます）
2. claude.ai/customize/connectors で Googleカレンダー・Gmail・Googleドライブをつなぐ
3. 秘書室に「毎朝の報告」を設定してもらう
4. 先月の売上データを分析部に渡す
